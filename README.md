## 🦁 멋쟁이사자처럼 제주대학교란?

> **멋쟁이사자처럼(LIKELION)** 은 전국 200여 개 대학교에 지부를 둔 대학생 IT 창업 동아리입니다.  
> **제주대학교** 지부는 제주의 열정 넘치는 학생들이 함께 코딩을 배우고, 서비스를 기획·개발하며 성장하는 공간입니다.  
> 개발 경험이 없어도 괜찮습니다. 배우고 싶은 **열정** 하나면 충분합니다. 🔥
